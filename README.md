# Yanfeng Wang | 王彦峰

Personal academic homepage. Published with GitHub Pages at:
https://lukjucy.github.io/Yanfeng-Wang.github.io/

## Publishing

In repository Settings → Pages, use **Deploy from a branch**, branch **main**, folder **/ (root)**. No build or package installation is required. Keep `.nojekyll` in the repository root.

The repository is a project site because its name differs from the account name. `https://Yanfeng-Wang.github.io/` is not the address for this repository.

## Updating

Edit `index.html` to update the visible biography, publications, education, experience, and awards. Styles are in `static/css/main.css`; `static/js/scripts.js` is retained as an empty compatibility file (no scripts are required). The historical `contents/` Markdown files are retained as reference and are not loaded by the page.

All essential content and navigation work without JavaScript or third-party CDNs. Use relative asset paths so the site works under the repository subdirectory.

## Local preview

Serve this directory using any static HTTP server, or open `index.html` directly in a browser.
